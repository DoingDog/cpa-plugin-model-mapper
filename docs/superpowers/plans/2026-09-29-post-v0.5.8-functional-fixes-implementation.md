# v0.5.8 后插件功能修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 阻止 executor 误用其他请求的 caller wildcard 缓存，并让 `DIST_DIR` 的构建、smoke、安装、清理指向同一完整路径。

**Architecture:** 只在当前 RPC 提供摘要与 `caller_scope` 匹配的原始凭据时使用 caller-pattern 缓存；route 与 executor 统一该规则，unscoped 映射保持可用。Makefile 将已有 `DIST_DIR` 明确传给本地 smoke helper，helper 将相对路径解析为仓库内路径，将绝对路径原样使用；安装与清理仅补 shell 引用。安全优先：CPA 没有两阶段共用的可信 request ID，因此取消 interceptor 删除/替换 credential 后继续应用 scoped wildcard 的旧行为，并在 README 说明。

**Tech Stack:** Go 1.26、`testing`、GNU Make、Git Bash、CPA Go `c-shared` plugin ABI。

**Spec:** `docs/superpowers/specs/2026-09-29-post-v0.5.8-functional-fixes-design.md`

## Review Focus

- [ ] **Step 3: 最小化修改 matcher 调用链**

`callerPatternMatchWithCallerCache` 在查询全局缓存**之前**校验 `key != "" && callerScope(key) == scope`，否则直接返回 `(false,false)`；去掉无凭据也读缓存的分支。route 和 executor 共同使用该规则，若 `allowUnboundCache` 因此成为未使用参数，则移除该参数及只为它存在的 wrapper，统一调用方，不改变缓存的容量、锁或热路径已绑定行为。对应代码形状：

```go
authenticated := key != "" && callerScope(key) == scope
if !authenticated {
    return false, false
}
// 只在当前凭据绑定成功后查询 callerPatternCache.current / previous。
```

保持 `callerMatchesRule` 对 `scope == ""` 和 inverse pattern 的早退行为。不要改成基于 `host_callback_id`、时间窗口或请求体哈希的关联。

- [ ] **Step 4: 将先前错误的拦截器保证改为明确安全断言**

将 `README.md:62,69-70` 关于跨阶段缓存、interceptor 改动 credential 仍能映射的承诺，改为：executor 仅使用本次请求仍携带的、与 `caller_scope` 绑定的 credential；若 interceptor 删除/替换该 credential，scoped wildcard 在 executor 不会执行，可能返回未处理错误；unscoped fallback 继续按规则运行。准确说明为什么没有 route->executor 可信关联，而不改变 DSL wildcard 不回溯说明。

- [ ] **Step 3: 修正 helper 与 Makefile 传参**

`smokePluginPaths(repoRoot, smokeDir)` 内读取 `os.Getenv("CPA_SMOKE_DIST_DIR")`，空值回退 `"dist"`，不删改路径中的前后空格；用 `filepath.IsAbs` 决定是否与 repoRoot 拼接。Makefile 的 `smoke-local` 命令对 go run 设置 `CPA_SMOKE_DIST_DIR="$(DIST_DIR)"`，确保其值与本目标在 `build-platform` 使用的值相同。

```go
distDir := os.Getenv("CPA_SMOKE_DIST_DIR")
if distDir == "" { distDir = "dist" }
if !filepath.IsAbs(distDir) { distDir = filepath.Join(repoRoot, distDir) }
return filepath.Join(distDir, runtime.GOOS+"_"+runtime.GOARCH, name),
    filepath.Join(smokeDir, "plugins", runtime.GOOS, runtime.GOARCH, name)
```

在 `Makefile` 中为 `cp $(WINDOWS_AMD64_OUT)`、`cp $(LINUX_AMD64_OUT)`、`rm -rf $(DIST_DIR)` 的路径加双引号，不更动其他构建/打包命令。
